📋 ESP32 Setup Guide

Step 1: Install Arduino IDE + ESP32 board support (espressif/arduino-esp32)

Step 2: Install libraries: Adafruit INA219, DHT sensor library, ArduinoJson v6

Step 3: Open hardware/esp32_sensor.ino and fill in WiFi credentials and backend URL

Step 4: Set SERVER_URL = "http://YOUR_SERVER_IP:8000/api/ingest"

Step 5: Flash to ESP32 and monitor Serial output. LED blinks = connected and sending data.

The ESP32 will POST sensor readings every 30 seconds. The dashboard automatically switches to LIVE HW mode when connected.
